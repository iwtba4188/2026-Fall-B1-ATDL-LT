# 2026-Fall-B1-ATDL-LT
Assignment 3 - Lottery Ticket

## Env Setup

1. Install the uv package manager following [uv Installation](https://docs.astral.sh/uv/getting-started/installation/).
2. Clone repo

   ```powershell
   git clone https://github.com/iwtba4188/2026-Fall-B1-ATDL-LT.git
   ```

3. Install packages and a virtual environment

    ```powershell
    uv sync
    ```

## Run tests

1. Run

    ```powershell
    uv run pytest
    ```
