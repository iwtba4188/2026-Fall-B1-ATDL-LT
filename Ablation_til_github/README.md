This folder 'Ablation_til_github'contains the 2 jupyter files that runs the phased matched ablation.  
These files are based on the project's python-files, which are found in this github's main branch. 
Jupyter files were chosen so that they could run fast on colab's GPU (e.g. the G4 GPU).
The first jupyter file creates and trains the deep learning model, which it outputs as a zip-file . 
The second jupyter file takes the zip-file as input and runs the phased matched ablation and returns the results described in our hand-in for assignment 3.
